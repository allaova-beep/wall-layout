# ПанельПро (PanelPro) — Инженерная система замера и передачи заказов в производство

Профессиональное веб-приложение (PWA) для выездных замерщиков и производственных цехов стеновых и акустических панелей.

## Возможности системы:
- **Замер стены по 3-м точкам лазером:** контроль кривизны стены (верх, центр, низ), расчет клина и автоматическое вычисление чистого габарита в распор.
- **Интерактивная раскладка со стыками:** подетальный векторный SVG-чертеж с миллиметровыми размерами, номерами панелей и размерными цепочками.
- **Автоматическая посадка розеток:** замерщик указывает координаты от угла комнаты ($X$) и от пола ($Y$), программа сама определяет номер панели, координаты для ЧПУ ($В$ и $П$) и предупреждает о коллизиях со швами.
- **Поддержка верхних доборов:** выбор между цельной горизонтальной балкой и составными ярусами («шов в шов»).
- **Спецификация для ЧПУ / станка:** экспорт деталировки в формат Excel (.CSV) с поддержкой кириллицы (UTF-8 BOM).
- **Складской чек-лист:** автоматический расчет норм дюбелей, акустического герметика, клея Момент, кондукторов Discus и звукоизоляционной минваты.
- **Каналы отправки:** мгновенная генерация структурированного наряда на производство для отправки по Email и в мессенджер MAX.
- **100% Офлайн (PWA):** работает без интернета в бетонных новостройках и подвалах.

## Структура проекта:
- `index.html` — главное автономное приложение (интерфейс, чертежи, калькулятор, экспорт).
- `manifest.json` — манифест для установки на экран смартфона/планшета как отдельной программы.
- `sw.js` — Service Worker для автономного кэширования и работы без сети.
- `icon.png` — иконка приложения для рабочего стола.

## Развертывание на Windows Server:
1. Включить службу IIS (Internet Information Services) или установить Nginx для Windows.
2. Скопировать содержимое репозитория в рабочую папку веб-сервера (например, `C:\inetpub\wwwroot\panelpro`).
3. Настроить доступ по локальной сети фабрики или через корпоративный домен / VPN.
